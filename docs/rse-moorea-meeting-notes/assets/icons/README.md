## Deliberately avoided

- BioRender and Noun Project coral assets were not downloaded because their terms are less convenient for a reusable proposal repository.
- The Bioicons `wound-healing` icon was not copied because it is human-biomedical imagery and CC BY 3.0; it is less accurate for coral wound experiments than a simple coral silhouette plus wound-treatment labels.
- The Bioicons `camera` and `Pipette` assets were tested but removed from the curated set because they render as detailed illustrations rather than clean proposal icons.
- Generic concrete or epoxy icons were not found in the science catalogs; labeled treatment boxes remain more accurate than decorative symbols.
